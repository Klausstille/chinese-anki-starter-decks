# Chinese Anki starter decks

Starter decks for the Chinese vocabulary web app. They use the app's
**Chinese (Basic)** note type, so cards you add later in the app look the same.

## HSK1 (150 words)

Each word has pinyin, a short definition, notes, four example sentences with
pinyin and English translation, and audio for the word and every sentence.

**Download:** [hsk1-starter.apkg](https://github.com/Klausstille/chinese-anki-starter-decks/releases/latest/download/hsk1-starter.apkg)

**Import:** open Anki → *File → Import…* → choose the downloaded file. The cards
appear in the deck `Mandarin: Vocabulary::HSK1`.
